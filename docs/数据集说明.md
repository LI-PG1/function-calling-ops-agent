# 数据集说明（ops-agent）

> 素材构成＝**自建合成数据（主）＋ 外部公开参考集（辅）**；数据本体不入库，外部集由 `python scripts/fetch_data.py` 一键下载与抽取（可完整重建）。
> **v0.2 更新（2026-07-29 → 10-16）**：题材从"设备运维"升级为"**出行服务编排**"——主素材改为**场景规则库 + 三类有状态 mock 服务 + 8 场景任务集**（下记 §零）；原型期设备素材降为历史留档/可选语料（§一/§二）。
> 本文件记录：来源、抽取结果、用途与接入点、数据质量、许可。

## 二、外部参考集（2026-07-27 抽取）

### 2.1 来源与抽取
- 约 105 万条维护工单 + 105 万条测点标签，覆盖 37 类工业设备；
- 抽取脚本 `scripts/fetch_data.py`：下载 → 按设备前缀抽取 → 设备 ID 规范化 → 输出 `data/raw/industrial_maintenance/`（不入库、可重建）。

### 2.2 抽取结果与设备映射

| 文件 | 对应合成设备族 | 源设备类型（前缀） | 条数 |
|---|---|---|---|
| `compressor_work_orders.csv` | ZX 系列螺杆式空压机 | Compressor / Air Compressor（K-*） | 62,410 |
| `pump_work_orders.csv` | KL 系列离心冷却泵 | Centrifugal Pump（P-*） | 171,624 |
| `conveyor_work_orders.csv` | QS 系列输送线驱动单元 | Belt Conveyor（CV-*） | 38,715 |
| `equipment_sensor_tags.csv` | 三类设备测点标签 | 同上前四类 | 182,176 |

### 2.3 用途与接入点

**用途 1｜故障模式核对（立即可用）**——合成手册的故障设计与真实工单中的高频故障模式逐族对照，确认"全虚构但符合真实故障规律"：

| 设备族 | 合成手册故障（示例） | 真实工单对应（示例） |
|---|---|---|
| ZX 空压机 | 排气温度超限报警 | High discharge temperature alarm（超跳机阈值） |
| ZX 空压机 | 运行异响 / 转速波动 | High vibration trip（轴承振动超标） |
| KL 冷却泵 | 轴封处持续滴漏 | Mechanical seal failure / product leak |
| KL 冷却泵 | 泵体振动超限、噪声 | High vibration alarm on drive end bearing |
| KL 冷却泵 | 启动后无流量（气蚀） | Cavitating intermittently / suction pressure |
| QS 输送线 | 输送带跑偏、边缘摩擦 | Belt mistracking / belt edge damage |
| QS 输送线 | 减速机异响、渗油 | Drive pulley / gearbox 相关工单 |

**用途 2｜历史工单语料（可选接入）**——为"查历史工单"类多步任务提供真实语料底座（剧本示例：查同类故障历史 → 对照手册 → 查备件 → 报修）；如引入，建议作为第 5 个工具（`query_work_order_history`）的数据源，施工时拍板。

**用途 3｜测点清单（可选）**——三类设备的典型测点（压力 / 温度 / 流量 / 振动 / 转速等，含单位与变量类型），可用于扩展场景或 demo。

### 2.4 数据质量说明
- 源数据含约 10% 真实数据质量问题（大小写 / 空格 / NULL / 无效日期如 `2021-06-41` 等）；本抽取已对 `Equipment_ID` / `Equipment_type` 规范化，其余字段保留原貌（如需"数据清洗"演示可直接利用）；
- 纪律：外部集仅作参考语料与对照，**不与全虚构手册混入同一条任务链路**（避免真实数据与虚构故障码混淆）。

## 三、函数调用 / MCP 工具调用评测参考集（2026-07-27）

> 定位：为"Function Calling / 技能注册 / 测评"深挖点提供**外部对照评测**与**技能设计参照**（自建任务集为主、外测为辅）。
> 拉取：`python scripts/fetch_data.py bfcl api_bank mcptoolbench`。

### 3.1 BFCL v3（Berkeley Function Calling Leaderboard）
- 来源：HF `gorilla-llm/Berkeley-Function-Calling-Leaderboard`（Apache 2.0）；落盘 `data/raw/bfcl/`；
- 构成：25 类测试文件共 5,251 条样例（simple 400 / multiple 200 / parallel / parallel_multiple / irrelevance / live_* / multi_turn_* / java / javascript / rest / sql）+ `possible_answer/` 标准答案 + `multi_turn_func_doc/` 工具文档 8 份；
- 用途：① **技能 JSON Schema 与描述写法参照**（工具文档形态与参数设计）；② 外测子集（如 simple + multiple）对照函数调用准确率。
- **执行记录（2026-08-02/16）**：外测五类全量 1240 条 → 首跑 **1116/1240 = 90.0%**；v0.2 后回归复跑 **1114/1240 = 89.8%**（无退化）；报告 `eval/report_bfcl.md`、运行器 `eval/run_bfcl.py`。

### 3.2 API-Bank
- 来源：HF `liminghao1630/API-Bank`（MIT）；落盘 `data/raw/api_bank/`（仅测试集，训练文件不拉取）；
- 构成：Level-1 调用判断 399 条 / Level-2 工具检索 135 条 / Level-3 多步规划 50 条（共 584 条）；
- 用途：技能选择准确率 / 参数填充准确率 / 多步规划能力对照；Level-3 的对话式规划可作多轮任务设计参考。
- **执行记录（2026-08-02/16）**：扩展集全量 779 条 → **548/779 = 70.3%**（L1 87.5% / L2 70.4% / L3 42.4%；判分 v2 = keywords 柔性匹配 + 生成侧 v2 = 格式纪律提示词，三轮演进 55.2% → 62.5% → 70.3%）；报告 `eval/report_api_bank.md`、运行器 `eval/run_api_bank.py`。

### 3.3 MCPToolBench++
- 来源：GitHub `mcp-tool-bench/MCPToolBenchPP`（MIT）；落盘 `data/raw/mcptoolbench/MCPToolBenchPP-main/`；
- 构成：6 类场景数据（browser / filesystem / search / map / pay / finance；单条含 `tools` / `mcp_tools_dict` / `query` / `function_call_label`）+ 评测 runner + MCP 工具定义（`mcp/tools/`）；
- 用途：① 与"技能 JSON Schema 注册（MCP 风格）"直接呼应——工具描述与调用标签可作**技能设计参照**；② pass^k 口径外测参考（map 子集含多语言，可覆盖中文）；MCPToolBench++ 外测为可选增强项。

### 3.4 BFCL v3 Multi-Turn（多轮函数调用，补充轨）
- 来源：同 3.1（BFCL v3 测试集中的 `multi_turn_*` 类）；执行器与 checker 为官方仓库 vendored（`eval/bfcl_multi_exec/`）；
- 构成：5 类 × 100 = 500 条（base / miss_func / miss_param / long_context / composite）；官方有状态 mock 类真实执行 + 官方 `multi_turn_checker` 判分（gold 自测 100/100）；
- **执行记录（2026-08-07/17）**：全量 500 条 → **126/500 = 25.2%**（base 44.0 / miss_func 18.0 / miss_param 26.0 / long_context 37.0 / composite 1.0；配置迭代全量复跑 +6，子集结论复现）；报告 `eval/report_bfcl_multi.md`、运行器 `eval/run_bfcl_multi.py`。
