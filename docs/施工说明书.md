### D5｜可靠性精读与实验

**目标**：吃透可靠性机制；亲手做三组注入实验。

**先理解（为什么）**：**异常向上传播（不吞异常）是第一纪律**——早期用 try-except 吞异常，导致"重试永远不触发"；重试 + 指数退避处理瞬时故障；逐工具超时防拖死；Semaphore 并发闸保护后端。

**动手**
1. 读 `src/reliability.py`：`call_tool`（重试 + 退避）、超时、Semaphore 的用法。
2. 三组实验（记录 attempts / 耗时 / 最终行为）：
   - 注入 `error` → 观察重试 3 次后放弃（看日志时间戳验证退避间隔）；
   - 注入 `timeout` → 观察重试 2 次后放弃；
   - 正常调用 → 1 次成功。
3. **v0.2｜安全护栏初体验**（读 `src/safety.py`，本日只建立体感，D9 深入）：
   - `pre_check` 实验：构造"行驶中开车门"类请求 → 观察**代码层直接拦截**（不经过模型）；
   - `post_review` 实验：构造一个高风险场景但输出缺安全提示的回答 → 观察被打回重写；
   - 在 `config/safety_rules.yaml` 里找 `fatigue_highway` 与 `moving_child_unattended` 两条，对比策略词（remind+navigate vs refuse+escalate）。
4. 顺带核查七件套现状（对照《设计方案》与 D10 要用的清单）：
   | # | 项目 | 现状 |
   |---|---|---|
   | 1 | 异常向上传播 | 不吞错、以"非结果"回填 |
   | 2 | 重试 + 指数退避 | `backoff=0.5` 起、指数增长 |
   | 3 | 逐工具超时 | 默认 2s |
   | 4 | 并发闸 | 全局 `Semaphore(4)` |
   | 5 | max_iter 硬限 | 8 |
   | 6 | 降级 | 触顶话术 |

### D8｜真实 LLM 入口

**目标**：亲手写运行入口 `app.py`；用真实 LLM 跑通任务。

**先理解（为什么）**：demo 用的是脚本化的 `ScriptedLLM`（离线确定性）；真实 LLM 会展示"为什么需要容错"的现场——偶尔不调工具、参数格式出错、多步迷路。**先亲手写入口，再对照参考实现。**

**动手**
1. 配 Key：`cp .env.example .env`，填三键（模型必须支持 Function Calling——DeepSeek / 通义 / GLM 均可）：
   ```
   LLM_API_KEY=sk-…
   LLM_BASE_URL=https://api.deepseek.com
   LLM_MODEL=deepseek-chat
   ```
2. **亲手写 `app.py`**（建议先自己写，再看参考）——最小实现参考：
   ```python
   """真实 LLM 入口：python app.py "任务描述"（需 .env 的 LLM_API_KEY）"""
   import pathlib, sys
   sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent))
   from dotenv import load_dotenv; load_dotenv()

   from src.llm import LLM
   from src.agent.loop import run_task
   from src.tools.spec import TOOLS

   task = sys.argv[1] if len(sys.argv) > 1 else "3 号空压机（ZX-110A）报高温故障 E-ZX-02，帮我处理并申请备件"
   result = run_task(task, LLM(), TOOLS, max_iter=8, timeout=5.0, retries=1)
   for s in result["trace"]:
       print(f"[iter {s['iteration']}] {s['tool']} ok={s['ok']} attempts={s['attempts']} args={s['args']}")
   print(f"\n完成={result['done']}｜迭代={result['iterations']}\n结论：{result['answer']}")
   ```
   > 签名速览：`run_task(task, llm, tools_spec, max_iter=8, timeout=2.0, retries=1)`。
3. 试跑 5 条（建议覆盖）：
   ```bash

   python app.py "3 号空压机（ZX-110A）报高温故障 E-ZX-02，帮我处理并申请备件"
   python app.py "ZX-110A-03 报 E-ZX-02，先看看压缩机油还有没有库存"
   ```

4. 记录**无规划基线**：工具选择是否正确 / 参数是否正确 / 迭代次数 / 失败点（D9 与 D12 都要对照）。
